# CLAUDE.md: working on SYNAPSE-2076

A Godot 4.3+ (GDScript) turn-based simulation. Read `README.md` for the product and `docs/SIMULATION_MODEL.md` for the math.

## Commands

```bash
tools/run_tests.sh                          # ALWAYS run before committing: import + lint + unit tests + 100-turn sim
tools/run_tests.sh --suite=dilemma          # one suite (substring of tests/unit/test_*.gd)
tools/run_tests.sh --suite=engine --filter=async
godot --headless --path . --script res://tools/check_scripts.gd             # compile every script/shader/scene
godot --headless --path . --script res://tools/monte_carlo.gd -- --runs=60  # balance report (run after touching the model)
godot --headless --path . --script res://tests/headless_sim_test.gd        # PRD smoke test
xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 1600x900 \
  --script res://tools/capture_dashboard.gd -- --out=/tmp/shots             # screenshot the real UI (no GPU needed)
xvfb-run -a godot --path . --rendering-driver opengl3 --resolution 412x915 \
  --script res://tools/capture_dashboard.gd -- --out=/tmp/shots --prefix=mobile_ --touch  # phone (1180x820: tablet split)
mkdir -p build/web && godot --headless --path . --export-release "Web" build/web/index.html  # needs the web_nothreads templates
(cd proxy && node --test)                                                   # Claude proxy (Cloudflare Worker) tests
tools/make_audio.sh                                                         # regenerate assets/audio (ffmpeg with libvorbis)
godot --headless --path . --script res://tools/i18n_catalog.gd -- --missing=de   # translation counts; strings left to translate
```

- **Godot binary.** Set `GODOT=/path/to/godot` if `godot` isn't on PATH.
- **Fresh clones** need `godot --headless --path . --import` once to build the `class_name` cache. `run_tests.sh` does this for you.
- **Godot 4.4+ writes `*.uid` files** next to scripts. The project targets 4.3; don't commit them (delete any a newer editor leaves behind).
- **Test runs keep player data apart.** `tests/run_tests.gd` points saves, endings and settings at `user://test_storage/` (`synapse/storage/*` project settings) and turns the tutorial off (`synapse/onboarding/coach`). Suites that change GameSettings put the values back.
- **CI** (`.github/workflows/ci.yml`) runs `tools/run_tests.sh` on Godot 4.3 and 4.7.
- **Pages** (`.github/workflows/pages.yml`) runs the same script on every push to `main`, applies the `SYNAPSE_LLM_*` repository variables with `tools/configure_web_build.gd`, then exports the Web preset with Godot 4.3 and deploys it to https://shotif.github.io/synapse-2076/.
- **LLM proxy** (`.github/workflows/llm-proxy.yml`, manual) tests and deploys `proxy/` to Cloudflare Workers. CI runs its tests on every push.

## Architecture rules

- **Headless-first.** Everything in `core/`, `entities/` and `systems/` extends `RefCounted` and must run without a scene tree. The only exception is `systems/llm/llm_service.gd`, a `Node` because `HTTPRequest` needs the tree. UI (`ui/`) and 3D (`viewports_3d/`) code binds through engine signals and never mutates simulation state directly. Player input goes through `SimulationEngine.submit_player_turn()`.
- **Deterministic.** All simulation randomness comes from `engine.rng`, which is seeded per campaign. Never call the global `randf()`/`randi()` in simulation code; the UI and 3D code may. Autonomous decisions are applied in `SimConstants.FACTION_ORDER` regardless of arrival order, and `HeuristicFallback` is a pure function of its input.
- **One mutation path.** Directives, crisis options, emergences, paradigm shifts and collapses are declarative effect dictionaries applied by `core/effect_resolver.gd`. World values change only through `WorldState.apply_delta()`/`set_value()`, which clamp to [0, 100], sanitize NaN/inf, and apply the interpretability drift multiplier. Faction currencies change through `ActorBase.add_resource()`.
- **LLM output is untrusted.** Route faction decisions through `PromptTemplates.validate_decision()`, crisis cards Claude writes through `CrisisWriter.validate_card()` (bounded costs and effects, never flags, injections or follow-ups) and negotiated offers through `Negotiator.validate_offer()` and `engine.preview_deal()`. Escape any text shown in BBCode labels with `CyberPalette.escape_bbcode()`. Never commit API keys: they come from `user://synapse_llm.cfg`, `SYNAPSE_LLM_API_KEY` or the web page URL (`#llm-key=`), never from `project.godot`, and never from a GitHub secret or variable for the public Pages build (`tools/configure_web_build.gd` refuses them).
- **Claude requests** use the Messages API (`/v1/messages`, auto-detected): `x-api-key`, `anthropic-version: 2023-06-01`, no `temperature`/`top_p`/`top_k` (current models reject non-default values), `output_config.effort` only where `LLMService.supports_effort()` allows it (not Haiku 4.5), `max_tokens` sized for thinking (`CLAUDE_MAX_TOKENS`), and replies read by text block, never `content[0]`. Faction decisions use `query_actor_decision()`; the crisis writer and negotiations use `request_completion()` (`completion_received`). The optional `proxy/` Worker forwards only that shape, up to 16 user/assistant messages.
- **Responsive UI.** `UiLayout.compute()` returns a `mode` from the window size, device pixel ratio and touch: `desktop` (1600x900 canvas: lens/intel column, the world, the ACT column, the newswire strip), `split` (landscape tablets and phones at least 760 logical px wide: the world beside one panel) or `phone` (one panel at a time). Compact modes run at about 1 logical px per CSS px. `MainDashboard.set_screen_mode()` arranges the panels behind the WORLD / ACT / LENS / NEWS tabs (`NavBar`; `show_tab()` still accepts `intel` and `log`) and calls `set_compact()` on every component. On phones nothing may force a width: wrap or clip labels and check boxes, and keep the desktop look when `compact` is false. Dialogs use `UiLayout.build_overlay()` so they scroll. Call `UiLayout.pass_touch_through()` on scrollable content so drags reach the ScrollContainer. `test_ui_dashboard.gd` fails if any visible control overflows a 412 px phone on any tab, dialog or era, or the split layout on a tablet.
- **Eras restyle everything.** `EraStyle` (`ui/theme/era_style.gd`) holds each hardware era's palette, fonts and shapes; `EraTheme.get_theme(era)` turns it into a Theme and publishes the values under the `Era` theme type. The dashboard applies the theme to itself; on an `ERA` log entry it shows the closing era's `FrontPage`, then plays `EraUpgrade`, which swaps the theme halfway through, and holds the crisis until both are done. Use theme type variations for stock controls. Custom-drawn widgets read `EraTheme.style_of(self)` and restyle on `NOTIFICATION_THEME_CHANGED`, but only when the era actually changed (gotcha 14). The faction lenses, the front page and the history book keep their own typography inside an era-shaped frame.
- **One glyph language.** Metrics, currencies, factions and UI icons are SVG paths in `ui/glyphs.gd` (`Glyphs.texture()`, `icon()`, `tile()`, `for_metric()`, `for_currency()`, `for_faction()`). ThorVG ignores `<text>`, so draw text with Godot. Effect previews use `UiFormat.pips()` and the era's good/bad colors (`UiFormat.is_improvement()`).
- **Story text.** `HeadlineWriter` turns log entries into headlines (the newswire and the globe's ticker), `EraChronicle` writes front pages and the history book's chapters, and `StoryCopy` holds their wording. Engine log entries carry structured extras for them (see `SimulationEngine._log()` callers); add extras rather than parsing `text`.
- **The engine pauses at two points.** `advance()` stops after presenting the player phase and after each turn's telemetry. Autoplay therefore needs two calls per turn, and `run_headless()` handles that.
- **Everything that shapes a campaign is recorded.** `engine.record` holds the seed, options, each player's answers and directives, every autonomous decision, cards written outside the deck and deals; `SimulationEngine.from_record(record, until_turn)` replays it (saves, Continue, "What if?" rewinds). A new source of decisions must be recorded too, and randomness must come from `engine.rng`. The UI changes the simulation only through `submit_player_turn()`, `apply_deal()` and `offer_external_card()`. `is_replaying()` is true while a record or a late start's prologue is being played; prologue log entries carry `prologue`.
- **Several people can play (pass-and-play).** `engine.human_roles` lists them and `engine.player_role` is whoever decides now (the first human outside the player phase). `player_input_required` fires once per human per turn; the dashboard rebuilds the lens and the newswire's perspective for that player and covers the hand-off with `PassDevice`. Deferred and scheduled cards belong to the player who caused them.
- **Every change has a cause.** Set `world.change_cause` around any new source of effects so `engine.get_changes(key, turn)` can explain it (the "why did this change?" popup). With several players, `_cause_for()` adds the player's faction to their own causes.
- **Text is translated (English, German, Spanish, French).** The English text is the message id. Wrap composed text in `tr()` (or `I18n.t()` in static code) before formatting it or passing it to `EraStyle.label()`; a plain literal assigned to a Control's `text` translates itself. Every new string needs an entry in `locale/de.gd`, `es.gd` and `fr.gd` with its {placeholders}, %-formats and BBCode kept (`test_i18n.gd` checks that each file translates exactly the catalog `tools/i18n_catalog.gd` collects). The simulation's own text stays English (logs, records, saves); crisis cards get translated copies for display (`DilemmaDeck.localized()`: `title_local`, `body_local`, `label_local`, `detail_local`). The news writers (HeadlineWriter, EraChronicle, StoryCopy) write English only. `I18n.apply()` follows GameSettings `"language"` ("" = the system language when translated).
- **Preferences live in GameSettings** (`ui/game_settings.gd`: text size, color-blind colors, plain language, effects, volumes, vibration, language, tutorial done). Components listen to `GameSettings.instance().changed`; `EraStyle.for_era()` and `EraTheme.get_theme()` already return the variant for the current text size and colors.

## Extending

- **New directive:**
  1. Add an entry to the faction's `ACTIONS` with `name`, `description`, `cost`, `cooldown`, `effects` and `statement`, using the effect schema in `effect_resolver.gd`.
  2. Add a rule to the faction's tree in `systems/llm/heuristic_fallback.gd` so the AI uses it.
  3. `tests/unit/test_factions.gd::test_catalog_effects_reference_known_keys` validates every key automatically.
- **New crisis card:** add a template to the era file it belongs to (`systems/cards/era1_cards.gd`, `era2_cards.gd`, `era3_cards.gd`; `CardLibrary` gathers them with the core `DilemmaDeck.CARDS`). Era cards carry their own headline copy (`"copy"`, the `StoryCopy.CARDS` schema) and swipe hints (`"swipe_hints"`, two labels of 12 characters or fewer). Every role must see at least 2 options (use `"roles"` for role-specific ones), every option needs a `cost` or `cost_tier`, and every role needs one answer at tier-1 cost or less. `test_dilemma_deck.gd` and `test_era_decks.gd` enforce this. Story chains use effects `"flags"`, `"characters"` and `"follow_up"`, conditions `requires_flags`/`lacks_flags`/`character_min`/`character_max`, and `"follow_up_only"` / `"once"`. Rival crises are injection families in `systems/cards/injection_cards.gd` (`"injection_head"` names the newswire line). A new `category` needs an illustration in `ui/components/crisis_art.gd` (`test_crisis_card.gd` checks).
- **New era goal:** add it to `EraGoals.GOALS`, with its threshold near what the heuristic reaches about half the time (measure it over 30–40 autoplay campaigns of that role).
- **New scenario:** add it to `Scenarios.LIST` (`ORDER` too) with its metric offsets, currencies, flags, card weights and an optional opening card.
- **New recurring character:** add them to `Characters.ROSTER` (the `look` drives the portrait) and give the cards that feature them `"character"`, effects on their score and `MEMORIES` lines.
- **Model or balance change:**
  1. Edit the named constants (`WorldState.K_*`, `*_REINFORCEMENT`, `ComputeScaling`, `TechTreeManager`).
  2. Run `tools/monte_carlo.gd` before and after the change.
  3. Keep `tests/unit/test_balance.gd` green.
  4. Update `docs/SIMULATION_MODEL.md` and its balance snapshot, and refresh `EndingsBook.SHARES` (the rarity table; its comment names the two Monte Carlo commands).
- **New end-state rule:** `core/victory_matrix.gd` holds the `OUTCOMES` (in priority order), `ROLE_OUTCOME_VALUE` and `CATASTROPHE_OUTCOMES`.

## GDScript / Godot 4.3 gotchas hit in this codebase

1. **`:=` on a Variant expression is a parse error** (INFERENCE_ON_VARIANT is an error by default). This shows up with loop variables over untyped arrays (`for x in [1.0, 2.0]`), dictionary values, and ternaries mixing types. Annotate the type instead: `var y: float = ...`.
2. **Packed arrays inside a Dictionary are copies.** `(dict["buf"] as PackedByteArray).append_array(x)` silently does nothing. Read the array into a local, modify it, and assign it back.
3. **A `SceneTree` script's `_initialize()` runs before the root window joins the tree.** `HTTPRequest`, timers and scene nodes added there aren't inside the tree yet, so `await process_frame` first. The test runner already does this.
4. **`class_name` globals only resolve after an import.** Run `--import` on fresh clones and in CI. Test suites extend the framework by path (`extends "res://tests/framework/test_case.gd"`).
5. **GDScript runtime errors don't change the exit code.** `tools/run_tests.sh` fails if output contains `SCRIPT ERROR`. A test that reports "no assertions ran" usually aborted on an error.
6. **The headless dummy renderer prints `mesh_get_surface_count` errors** when a mesh instance and its mesh are freed together. Viewports call `GlobeViewport.release_meshes(self)` in `_exit_tree()`, and line meshes are rebuilt in place (`clear_surfaces()`) instead of being replaced.
7. **`const` Dictionaries and Arrays are read-only.** `duplicate(true)` before mutating templates (see `DilemmaDeck._resolve_option`).
8. **Don't load class_name scripts with `CACHE_MODE_IGNORE`:** it can segfault 4.3 (seen in `tools/check_scripts.gd`).
9. **The Web build is single-threaded.** Keep `variant/thread_support=false`: GitHub Pages can't send COOP/COEP headers, so a threaded build won't start there. Export into `build/`, whose `.gdignore` stops Godot from importing the output and packing it into the next export. Web builds never auto-probe the default localhost LLM endpoint (`LLMService.should_auto_probe()`).
10. **`PanelContainer` and `Button` default to `MOUSE_FILTER_STOP`.** A touch drag that starts on one never reaches the enclosing `ScrollContainer`, so phones can't scroll. `UiLayout.pass_touch_through()` switches them to PASS; Godot then cancels the pressed button once the drag turns into a scroll.
11. **A `ScrollContainer` with horizontal scrolling off is as wide as its content plus the vertical scrollbar.** A full-width phone panel then overflows by the bar's width; compact overlays hide the bar (`SCROLL_MODE_SHOW_NEVER`, drag still scrolls).
12. **`HBoxContainer`/`VBoxContainer` can't change orientation at runtime** ("Can't change orientation"). Use a plain `BoxContainer` and set `vertical` when a row must stack on phones.
13. **`RichTextLabel` has no touch-drag scrolling in 4.3.** Put it in a `ScrollContainer` with `fit_content = true` (the history book does).
14. **Changing a control's own theme overrides, or a StyleBox it uses as an override, inside `NOTIFICATION_THEME_CHANGED` sends the notification again.** That recursion overflows the stack. Restyle only when the era changed (`EraTheme.style_of(self).era != _era`) or guard with a flag (`NavBar`, `LLMStatusBadge`).
15. **`set_anchors_preset()` on a control that is already in the tree keeps its old rectangle** (the offsets are recomputed). Overlays built in code use `set_anchors_and_offsets_preset(Control.PRESET_FULL_RECT)`, or they stay 0x0.
16. **Any `text_overrun_behavior` other than no trimming lets a `Label` shrink to the ellipsis.** In a container that doesn't expand it, the text vanishes; an autowrapped label also loses its minimum height. Trim only where the label gets room (`SIZE_EXPAND_FILL`).
17. **Headless runs measure text about three times too tall and the root window is 64x64.** Don't assert pixel heights in unit tests, and send synthetic input with `Viewport.push_input(event, true)` (see `test_crisis_card.gd`).
18. **An autowrapped `CheckBox` keeps the height it measured at an earlier, narrower width** (one word per line, over a thousand pixels tall). Once its panel has a width, set `autowrap_mode` again to measure it anew (`LLMSettingsDialog._reflow_checks()`).
19. **Taps go to the last control in tree order, whatever its `z_index`.** Overlays that must take input over others are added later: the coach and the pass-the-device cover are the dashboard's last children.
20. **Labels and Buttons translate their own `text`.** A translation that happens to equal another English message id is translated again, so text that is already translated or generated (news, LLM replies, player input) sets `auto_translate_mode = AUTO_TRANSLATE_MODE_DISABLED`.
21. **`NOTIFICATION_TRANSLATION_CHANGED` also arrives while the change propagates and when a control enters the tree.** Handlers that add or remove nodes must defer that work.

## Layout

`core/` simulation engine and math, difficulty, scenarios, era goals, campaign modes · `entities/` factions · `systems/` compute physics, crisis deck (`cards/` the era decks and injection families), recurring characters, saves, endings book, turning points, LLM layer (`llm/`: service, prompts, heuristics, crisis writer, negotiator) · `ui/` dashboard (`components/` widgets and dialogs, `lenses/` the four faction lenses, `story/` newswire, front page, chronicle and share card, `theme/` era styles and themes, `effects/` backdrop, transition and glitch shaders, `audio/` the audio director; `game_settings.gd`, `plain_language.gd`, `haptics.gd`) · `locale/` German, Spanish and French strings (`ui/i18n.gd` loads them) · `assets/audio/` era music and effects, synthesized by `tools/make_audio.sh` · `viewports_3d/` globe, lattice and shaders · `tests/unit/` suites (one file per area) · `tools/` lint, Monte Carlo, capture and audio scripts · `docs/` model spec, design directions and screenshots · `proxy/` optional Claude API proxy (Cloudflare Worker, plain JS, Node tests).
